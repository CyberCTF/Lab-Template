# Generation artefacts

Where generation artefacts go.

Artefacts produced while generating the lab, such as `SCENARIO.md` and `EVIDENCE.md`, go in `.ctf/`.

Use this folder for any file you need while generating the lab that is not part of the final
result. The lab itself is `isoloom.yml`, `build/`, `provision/`, `tests/` and the generated `.isoloom/`.
